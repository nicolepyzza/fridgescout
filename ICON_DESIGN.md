# FridgeScout App Icon Design

## Design Concept
Create a 1024x1024px icon with this design:

### Style: Minimalist, Modern
- Background: Gradient from #0b0f14 (dark blue) to #1a2530 (lighter blue)
- Main Element: White refrigerator outline/silhouette
- Accent: Small green checkmark or scanner beam effect

### Quick Creation Options:

**Option 1: Use Canva (Easiest)**
1. Go to Canva.com
2. Create 1024x1024 design
3. Add gradient background (#0b0f14 to #1a2530)
4. Search "fridge icon" or "refrigerator icon"
5. Add white fridge icon in center
6. Add small green accent (scanner line or checkmark)
7. Download as PNG

**Option 2: Use Figma**
1. Create 1024x1024 frame
2. Add gradient background
3. Draw simple fridge shape (rectangle with rounded top)
4. Add door handle line
5. Export as PNG

**Option 3: Hire on Fiverr**
- Search "app icon design"
- Budget: $5-20
- Provide: "FridgeScout - food tracking app, needs minimalist fridge icon on dark blue gradient"
